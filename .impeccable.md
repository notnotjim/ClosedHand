# ClosedHand Design Context

## Target Audience
Young professionals (25-40) who want a personal AI assistant that connects to their real tools (email, calendar, files, apps). Tech-comfortable but not necessarily developers. Users who value privacy and want their AI to work for them, not a corporation.

## Use Cases
- Chat with an AI that can read email, check calendar, search the web, manage files
- Connect services (Google, Shopify, Meta, Slack, etc.) and have the AI work across them
- Run background agents/workers for research, monitoring, and automation
- Manage a personal knowledge base (Context Brain) that the AI learns from over time
- Use from any device: web, Telegram, WhatsApp, Discord, Slack, LINE

## Design Context

### Users
Tech-comfortable young professionals (25-40) who distrust Big Tech's data practices but still want a capable AI that reaches their accounts and computer. They're comfortable in chat apps (Telegram/WhatsApp/Discord/Slack/LINE), a web dashboard, and pairing a desktop bridge. Context of use is multi-device and switches often between conversational (chat) and operational (files / desktop / browser) modes. The job to be done: *"Give me one assistant that can reach my computer and my accounts safely, without a Big Tech surveillance rider. Let me stay the owner of my stuff."*

### Brand Personality
Three words: **authentic, capable, fun** — with *private* as the non-negotiable backbone.
- **Authentic over polished.** This is an indie project sticking it to the man, not a SaaS with a deck. If it's polished it's because craft, not because conformity.
- **Fun, with earned easter eggs.** Small, specific moments of delight — tied to repeated actions the user will actually hit (sign-in, pair-bridge, long-job-done) — not ambient sparkle.
- **Capable, understated.** Doesn't need to look flashy to be powerful. British dry wit, direct copy, no corporate speak, no emdashes, no AI-sparkle vocabulary. Think Bloomberg Terminal meets iMessage — with a hand-drawn bird in the corner.
- **Privacy-first is the promise.** Trust is the USP. Your data is yours. The fist mark holds this.

Emotional goals: confidence (it works), solidarity (*this is mine, not theirs*), and delight.

### Aesthetic Direction
**References:**
- **Paperclip (paperclip.dev)** — illustration as a hero device, bold editorial serif for display type, confident narrative copy, layouts that don't look like anyone else's. A feast for the eye, not a template.
- **Hasui Kawase (川瀬巴水, 1883-1957)** — Shin-hanga woodblock master. Atmospheric prints of moonlit temples, rainy streets, snow-covered shrines, misty lakes, lantern-lit alleys. This is the illustrative register ClosedHand uses: hand-crafted, moody, time-of-day specific, evocative. Public-domain Kawase prints (pre-1929 works) serve as empty-state hero art, rotating by time of day (dawn / morning / afternoon / dusk / night) or randomly to reward repeat visits. No other AI product looks like this — which is exactly the point.

**Anti-reference (the "AI look"):** Tailwind-blue / indigo / purple accents, over-reliance on cards + pills + glass/blur, gradient orbs, sameness across ChatGPT / Claude / Copilot / Cursor / Notion-AI / Perplexity. Interchangeable dashboards. *Designed-by-a-component-library* feel.

**Theme:** dark-only for now. Background stays near-black (`#040406`). A light variant may come later as an inverted version.

**Signature elements to introduce:**
- **Kawase woodblock prints** rotating by time of day (and occasional rain/snow variants), used as **background texture only** — never as foreground hero on the Cloud/Local CTAs where icon clarity matters more. Good future locations: subtle hero backdrop, dashboard welcome, long-running-job "we're working on it" screens. Sourced from Wikimedia Commons with per-print museum credit (Rijksmuseum etc). Attribution line always visible where the art appears.
- **Fraunces serif display face** for H1/H2 headlines (variable font, carries warmth).
- **IBM Plex Sans** for body and UI chrome. Plex pairs better with Fraunces than Outfit (too quirky) or Geist (too neutral) — both faces carry a slight publication-history lean without competing.
- **Flat panels over glassmorphism.** Drop `backdrop-filter: blur()` in non-modal chrome. Solid dark panels with subtle borders. Blur is reserved for true floating modals.
- **Mint accent `#6ee7a8` stays sacred but rationed.** If it's everywhere, it's nowhere.
- Panel accents: Cloud = `#60a5fa` blue, Local = `#f59e0b` amber. Kept as signal (status, hover-into) not decoration.
- The fist mark is the identity constant across all surfaces (web, bridge, chat-app avatars).

### Design Principles
1. **Be a benevolent source of good.** ClosedHand is a gift, not a product being sold. Every surface should carry a small considered touch: art attributions (artist + title + year whenever art appears), warm error copy that treats the user as a friend, little acts of quiet thoughtfulness. Signal that a human cared about the moment you're in. Never transactional, never algorithmic.
2. **Earn attention through craft, not flash.** One strong visual moment per surface. Not eight gradient cards.
3. **Typography carries the voice.** Pair a serif display face with Outfit body. The type is editorial, not SaaS.
4. **Materials over glass.** Flat panels, hand-drawn strokes, subtle grain. Blur is reserved for true modals.
5. **Restraint makes the accent work.** Monochrome first; mint green is a punctuation mark.
6. **Delight is specific, not sprinkled.** Named easter eggs tied to repeat actions — never ambient hover sparkle.
7. **Usability is the floor.** Break visual conventions freely, but never at the cost of glance-comprehension.
8. **Indie tells, not indie costume.** Hand-drawn assets and warm copy should feel like a person made this — not a startup cosplay.

## Technical Constraints
- Vanilla HTML/CSS/JS only. No React, no Tailwind, no build step.
- Inline styles and scripts in HTML files (legacy architecture).
- Must work across all modern browsers and mobile Safari.
- Two pages carry 99% of the UI: `webapp/views/index.html` and `webapp/views/dashboard.html` (~7k lines each). Any aesthetic refactor is CSS + inline markup/SVG, not a framework swap.
- Chat surfaces run inside Telegram/WhatsApp/Discord/Slack/LINE, so the product's identity has to land through copy, tone, and occasional illustrated assets — not through app chrome.
