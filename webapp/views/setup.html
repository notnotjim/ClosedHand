  1. 01

    ClosedHand keeps memories, mail indexes and settings in a database that belongs to you. It arrives with the install and starts on its own, so this step usually lights up before you ever see it.

    Not lit yet? The database can take a minute on first boot. If it stays dark, something went wrong with the install itself; re-running the installer is the quickest fix.

  2. 02

    Paste an API key. ClosedHand works out which provider it belongs to and runs the best models that key can reach.

    ClosedHand identifies the provider from the key itself.

    The dashboard holds everything ClosedHand knows about you. Pick a password and from then on the dashboard asks for it; there is no username, because this instance has exactly one owner.
